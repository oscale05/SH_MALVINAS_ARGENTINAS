# UI/UX

Principios:
- Mobile-first.
- Lectura rápida para observador.
- Administración clara para operador.

Pantallas observador:
- Macro KPIs.
- Origen.
- Eje.
- Secretaría.
- Subsecretaría.
- Dirección.
- Concepto.

Pantallas operador:
- Login.
- Upload Excel.
- Historial de cargas.
- Errores de validación.
- Gestión de usuarios/roles.

Componentes:
- Cards KPI.
- Gráficos.
- Tablas con drill-down.
- Filtros persistentes.
