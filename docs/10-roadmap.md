# Roadmap

Fase 1: modelo de datos + parser Major + carga.
Fase 2: API dashboard cascada + roles.
Fase 3: frontend Angular responsive.
Fase 4: tests, CI, deploy.
Fase 5: evaluación Flutter.

Riesgos:
- Cambios en formato Excel Major.
- Performance con datasets grandes.
- Complejidad de reglas contables.

Mitigaciones:
- Adaptadores de fuente.
- Índices y agregaciones.
- Documentación de dominio y validaciones.
