# Deploy

Entornos:
- local
- staging
- production

Requisitos:
- PHP 8.3/8.4
- Composer
- Node/Angular CLI
- Base de datos
- Storage para uploads

Procesos:
- Migraciones versionadas.
- Backups de BD y uploads.
- Variables de entorno.
- Logs de aplicación.

CI/CD:
- Tests automáticos.
- Build Angular.
- Deploy por rama.
