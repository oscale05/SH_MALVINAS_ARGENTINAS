# Contexto

Sistema de observación de datos de hacienda (ingresos) del Municipio de Malvinas Argentinas.

Objetivo: tablero de comando con efecto cascada, mobile-first, para consulta por el Secretario de Hacienda y operación por usuarios autorizados.

Fuente inicial: Excel Major. Futuro: otros formatos mediante adaptadores.

Roles:
- Operador: carga/validación/administración web.
- Observador: consulta de dashboards en web/móvil.
