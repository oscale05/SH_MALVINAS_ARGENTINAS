# UI/UX

Principios:
- Mobile-first, responsive.
- Lectura rápida para observador.
- Administración clara para administrador.

Pantallas:
- Login con autocompletado
- Dashboard con KPIs, gráficos y cascada
- Carga de Excel con validación
- Historial de uploads
- Gestión de usuarios
- Health check

Componentes:
- Cards KPI.
- Gráficos de barras (ng-icons para iconografía).
- Tablas con drill-down.
- Filtros persistentes.
- Banner de conexión offline.
- PWA instalable.

Navegación:
- Cascada: macro → origen → eje → secretaría → subsecretaría → dirección → concepto
- Autocompletado por código, origen o concepto.
