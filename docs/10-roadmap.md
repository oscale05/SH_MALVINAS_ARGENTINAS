# Roadmap

Completado:
- Modelo de datos + parser Major + carga.
- API dashboard cascada + roles.
- Frontend Angular responsive.
- PWA offline.
- Tests, CI, deploy Apache.
- Ampliaciones de presupuesto.
- Observación mensual (pendiente implementación completa).

Pendiente:
- Flutter (evaluado, PWA elegido).
- Más pruebas E2E.
- Validación en producción.

Riesgos:
- Cambios en formato Excel Major.
- Performance con datasets grandes.
- Complejidad de reglas contables.

Mitigaciones:
- Adaptadores de fuente.
- Índices y agregaciones.
- Documentación de dominio y validaciones.
